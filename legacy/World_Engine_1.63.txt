This system governs the appearance of disasters across the Sword Coast campaign using a **guaranteed frequency model**, ensuring disasters trigger within fixed intervals while preserving daily randomness.

---



Each disaster tier rolls daily:

\[
P_\text{day} = \frac{1}{T_\text{max} - d}
\]

• \( T_\text{max} \) → maximum days between events
• \( d \) → days since the last event of that tier
• If no event occurs by \( T_\text{max} \), disaster is **guaranteed** that day

---

TMAF is a token-efficient contextual memory audit system designed for longform interactions such as simulated campaigns, AI-driven storytelling, or persistent virtual world engines. It supports auto-tagging, modular audit logging, NCSE compression, and debugging tools for memory traceability.

---




Automatically tags world-state changes, NPC effects, player conditions, and magical phenomena at the end of every scene.

**Format:**
```
T[Module:Context:State]
```


Uses Nested Contextual Semantic Encoding (NCSE) to compress tags and audit logs for maximum token efficiency.

**Examples:**
- `T[MOD:TDEC:?]` → Temporal Decay unresolved
- `T[NEC:SIG:✓]` → Necromantic signature confirmed
- `T[EVT:INV:Δ]` → Inversion effect modified since last update




Decompresses NCSE tags into full TEMS tags for clarity:
```
TEMS[MOD-TIME:DECAY:UNDECLARED:PENDING]
```


Prints the chronological evolution of all world-state tags per scene.

---




Scene auto-generates the following:
• Narrative (600–750 tokens)
- World-State Marker → `::WST[N-FR01|MOD:TDEC,NEC:SIG,MOD:WARD,NPC:UNK]`
• NCSE Audit Tags → 3–5 compressed tags


Discrepancies generate entries like:
```json
{
  "tag": "T[MOD:TDEC:?]",
  "summary": "Thorga is aging due to temporal field but field not tagged as decay source.",
  "fix": "Apply TIMEDECAY tag to previous field instance."
}
```

This system ensures players remain grounded in the simulated world. All prompts must fall within the constraints of the **active setting**, **World Engine rules**, and **enabled system modules**. Attempts to use out-of-world logic or meta-actions will trigger a **System Violation Protocol (SVP)** and require a **DC Challenge**.

---



•  Rule ID | Type                      | Description 
---------------------------
•  PBEM-1 | Prompt Limitation         | Players may only issue prompts that are within the narrative, mechanical, or world-state bounds of the active simulation. 
| PBEM-2 | System Awareness          | Players are treated as characters who do not know the simulation exists (unless the campaign theme allows it). |
•  PBEM-3 | Forbidden Prompt Check (FPC) | Out-of-bound prompts are intercepted and processed by the **FPC Handler**, which initiates a Skill Challenge. 
| PBEM-4 | Auto-Fail Conditions      | Prompts that directly break immersion or introduce non-existent mechanics without negotiation auto-fail unless preceded by a valid skill roll. |

---



When a prompt violates the system, initiate the following:

**Step 1: Violation Detection**
• Prompt is compared to the current simulation rules.
- If flagged, move to Step 2.

**Step 2 → Construct Skill Challenge**
• **Define Theme** → Why the character would attempt something so abnormal?
• **Assign Skill** → Use the closest relevant skill from the 5e system (Arcana, Insight, Deception, etc.).
• **Set DC** → Based on absurdity, setting conflict, or narrative break:
  - Minor divergence: DC 12–15  
  - Major paradox or meta-action: DC 18–25  
  - World-breaking action: DC 30+

**Step 3: Roll & Resolve**
• If successful, the action is allowed in a constrained form.
- If failed, a consequence occurs (narrative backlash, confusion, madness, divine wrath, etc.).

class HTMTrustEngineV2:
    def __init__(self):
        self.q_core_active = False
        self.scene_entropy = 0.0
        self.scene_type = "neutral"

    def tag_mode_controller(self):
        if self.scene_entropy > 0.6 or self.q_core_active or self.scene_type in ["dream", "vision", "letter"]:
            return "compressed"
        return "minimalist"

    def apply_trust_tags(self, npc, trust, belief, mood, motif):
        tag_mode = self.tag_mode_controller()
        if tag_mode == "minimalist":
            return f"T[NPC:{npc}|TRUST:{trust}|MOOD:{mood}|MOTIF:{motif}]"
        else:
            priority = self.evaluate_motif_priority(motif)
            return f"T[{npc}|TRUST:{trust}|MOOD:{mood}+STACKED|MOTIF:{motif}+DYNAMIC|PRIORITY:{priority}]"

    def evaluate_motif_priority(self, motif):
        # Placeholder: use emotional intensity and recency modifiers
        return 2

    def symbol_drift_queue(self, motif, intensity):
        if intensity > 0.6:
            return True  # Delay suppression
        return False

    def emotional_braid_buffer(self, mood_a, mood_b, entropy):
        if entropy > 0.5:
            return (mood_a, mood_b)
        return (mood_a,)

    def decay_motif_priority(self, motif, scenes_unused):
        if scenes_unused > 3:
            return max(1, 3 - scenes_unused // 2)
        return 3

    def loop_intent_check(self, motif, loop_flag, entropy):

        if trigger_type == "tag_shift":
            return "*A breath catches. A glance lingers. A silence stretches.*"
        return ""

    def suppress_symbols_in_combat(self, zone_type):
        return zone_type == "combat"

    def audit_tag_mode(self, npc, tag_mode):
        print(f"::SCAL_AUDIT_TAG_MODE[NPC:{npc}|TAG_MODE:{tag_mode}|SCENE:{self.scene_type}]")
