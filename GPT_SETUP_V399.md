# GPT Setup — World Engine v3.9.9

After `INSTALL_PERMANENT_ENDPOINT.bat` reports PASS, import `openapi_actions_PERMANENT.json` once and configure Bearer authentication with **Copy API Key**.

The no-admin default uses an ngrok account-assigned stable HTTPS domain. Normal endpoint crashes are automatically restarted by the launcher/verifier. A reboot requires this Windows user to sign in; the Startup entry then restores the backend and tunnel.
